# Sheniya — Animated Responsive Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript.

## Run
1. Extract the ZIP and open the folder in VS Code.
2. Run `index.html` with Live Server.
3. The résumé is available at `assets/resume.pdf` when included in the ZIP.
4. Add the generated talking intro video at `assets/intro.mp4`.

## Features
- Responsive desktop, tablet and mobile layouts
- Smooth scrolling and section reveal animations
- Floating hero particles and subtle cursor glow on desktop
- Animated hover states for buttons, projects, skill cards and certifications
- Scroll-to-top button
- Gmail compose link and copy-email fallback
- Resume download button
- Reduced-motion accessibility support

## Before publishing
Test the resume download, intro video and all project links. Deploy the folder to Netlify or GitHub Pages.
