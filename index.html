01 / AI

AUREX AI — Full-Stack AI Assistant

AUREX AI is a full-stack AI assistant designed to provide context-aware responses through an interactive chat interface. It includes user authentication and persistent chat history, allowing users to manage conversations across sessions. Users can upload PDF documents and ask questions about their content using Retrieval-Augmented Generation (RAG). The system retrieves relevant document information and uses an LLM API to generate answers. Source references, including page numbers and excerpts, help users trace responses back to the supplied documents.

Key Features

  • User registration and authentication
  • Persistent chat history and conversation management
  • PDF upload and document processing
  • RAG-based question answering
  • Vector-based document retrieval with Chroma
  • AI response generation using the Groq API
  • Source references for answer verification
React TypeScript FastAPI PostgreSQL Chroma Groq API

02 / AUTOMATION

AI Office Assistant — Workflow Automation

AI Office Assistant is an AI-powered workflow built with n8n to automate the initial handling of employee requests. It uses an LLM through OpenRouter to classify messages into Leave, IT Support, Payroll, HR, or Other. Based on the classification result, the workflow directs each request through the appropriate automation path and prepares manager notifications containing the original employee message and suggested next steps. The project demonstrates how AI classification and conditional workflow automation can help organize repetitive internal office tasks.

Key Features

  • Automated classification of employee messages
  • Five categories for common office requests
  • Conditional routing based on classification results
  • Manager notification workflow
  • Original employee message included in notifications
  • AI-generated suggestions for handling requests
  • Docker-based local environment setup
n8n OpenRouter LLM Integration Google Drive Gmail Docker

03 / WEB APP

LeaveFlow — Leave Management System

LeaveFlow is a web-based leave management system designed to simplify leave applications and approvals for employees and managers. Employees can log in, view their dashboard, check available leave balances, submit requests, and review their leave history. The application validates date ranges and checks leave balances before processing applications. Managers can review pending requests and approve or reject them. A calendar interface visually distinguishes approved, pending, rejected, and holiday dates, helping users understand leave schedules more easily.

Key Features

  • Employee registration and login
  • Employee dashboard with leave summaries
  • Leave application with type, dates, and reason
  • Start-date and end-date validation
  • Leave-balance validation
  • Leave history and calendar visualization
  • Manager approval and rejection workflows
  • REST API and relational database integration
HTML CSS JavaScript FastAPI SQLAlchemy PostgreSQL

FlyBird — Interactive Flying Bird Game

FlyBird is a browser-based flying game built with React and TypeScript.
